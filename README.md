# OCR PDF скрининга

Простое Streamlit-приложение для:
- загрузки PDF скрининга;
- OCR распознавания текста;
- извлечения ключевых признаков;
- предсказания осложнений по извлечённым данным скрининга (если доступен файл модели);
- экспорта результатов в CSV/JSON.

## Запуск

```bash
uv run streamlit run main.py
```

## Структура

- `main.py` — точка входа.
- `app/config.py` — настройки приложения и OCR.
- `app/ocr.py` — OCR и обработка PDF.
- `app/parser.py` — парсинг признаков из текста.
- `app/predictor.py` — загрузка модели и предсказание осложнений.
- `app/ui.py` — Streamlit UI.

## Linux и автоматизация

Для автоматизации разработки и работы с проектом используются Bash-скрипты, `tmux` и `Makefile`.

### Папка `scripts/`

```text
scripts/
├── check_project.sh
├── run.sh
├── dev.sh
└── monitor.sh
```

- `check_project.sh` — проверяет структуру проекта, ищет Python-файлы, считает строки кода, ищет ML/OCR-компоненты и проверяет наличие основных файлов.
- `run.sh` — запускает Streamlit-приложение. По умолчанию используется порт `8501`, порт можно передать первым аргументом.
- `dev.sh` — создаёт `tmux`-сессию для разработки с двумя окнами: `nvim` и `codex`.
- `monitor.sh` — создаёт `tmux`-сессию с информационными панелями для мониторинга процессов, памяти, дискового пространства и состояния проекта.

Примеры:

```bash
./scripts/check_project.sh
./scripts/run.sh
./scripts/run.sh 8502
./scripts/dev.sh
./scripts/monitor.sh
```

Скрипты используют переменные, аргументы командной строки, условия и циклы Bash для автоматизации повторяющихся операций.

### Makefile

Makefile предоставляет единую точку входа для основных операций проекта.

```bash
make help
```

Доступные цели:

| Команда | Назначение |
|---|---|
| `make help` | показать доступные команды |
| `make check` | проверить структуру и код проекта |
| `make run` | запустить Streamlit-приложение |
| `make dev` | запустить окружение разработки в `tmux` |
| `make monitor` | запустить окружение мониторинга в `tmux` |
| `make stop` | остановить созданные `tmux`-сессии |
| `make clean` | удалить временные Python-файлы и кэш |

Например:

```bash
make check
make dev
make monitor
```

Использование Makefile позволяет заменить последовательность ручных команд одной командой и упрощает повторный запуск типовых операций.
